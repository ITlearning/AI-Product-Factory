# 몽돌 — App Store 미리보기 6장

작성 2026-10-03 · 상태 **승인(Tabber, 대화)** · 한국어 스토어 · 6.9인치 1320×2868 × 6장

## 목표

처음 보는 사람이 6장을 넘기며 세 가지를 안다 — **찍을 땐 색을 안 보여 준다 → 하루가 끝나면 그날 색이 조약돌로 온다 → 그게 조용히 쌓인다.**
그리고 「갖고 싶다」가 남는다. 감성·취향은 반증 대상이 아니다([`color-moments.md`](color-moments.md) 세션 계약).

## 구성 — A안 「여섯 장이 하루 하나」 (Tabber 선택)

7920×2868 캔버스 한 장에 그리고 1320씩 잘라 6장을 만든다. 배경은 끊기지 않는 하루 그라데이션
(새벽 남색 → 하늘 → 낮 크림 → 노을 살구 → 분홍 → 밤 보라)이라 6장을 다 넘기면 세트 전체가 조약돌 하나가 된다.
폰은 기울어진 채 장 사이를 넘나들고(2→3, 5→6), 문구는 위·아래를 번갈아 둔다(1·3·5 위, 2·4·6 아래).

- 2장 작은 문구는 「카메라 컨트롤」을 앞세우지 않는다 — 그 버튼은 iPhone 16 이상뿐이다. 잠금화면 컨트롤은 iOS 18 전 기종(iPhone 13 실기기 확인 2026-10-03)이고, 기본 카메라로 찍어 골라 담는 길도 있다.
- 5·6장은 처음 「모은 조약돌 / 한 달 한 줌」이었다가, 받은 스크린샷(홈과 모은 조약돌)에 맞춰 바꿨다.
- 뺀 것: 건네기(결과 공유 권유 금지), 위젯, iCloud.

## 시각 규칙

- 바탕 `#06070A` + 하루 색 번짐. 아이콘 조약돌에서 뽑은 색, 앱 증정(0.42)보다 조금 진하게 0.5~0.6 — 스토어 썸네일이 작다. 고운 입자 한 겹(줄무늬 방지).
- 큰 문구 나눔명조 Bold ≈96px 흰 92% · 작은 문구 고운돋움 ≈44px 흰 64%. 앱의 명조는 113자 서브셋이라 마케팅용은 전체 판(OFL)을 쓴다.
- 폰: iPhone 16 Pro 모양을 CSS로 그린다(검은 테두리 · 다이내믹 아일랜드 · 깊은 그림자). 화면엔 실제 스크린샷(1206×2622).
- 상태 막대는 9:41 깔끔한 막대로 덮는다(실제 시각·배터리 숨김). 뷰파인더의 카메라 사용 초록 점은 지운다.
- 1장 조약돌은 아이콘 원본, 가장자리를 둥글게 지워 바탕에 녹인다(네모 테두리가 비쳤던 문제).

## 지키는 제약 (SPEC §2)

찍는 순간의 색을 보여 주지 않는다 · 격자·스트릭처럼 보이지 않는다 · 재촉하지 않는다 · 판단하지 않는다 · 결과 공유를 권하지 않는다.

## 제작

- `Color-Moments/marketing/app-store/` — `index.html`(캔버스) + `render.sh`(헤드리스 브라우저로 1320px씩 밀어 6번 찍기) + 글꼴(OFL).
- 원본 스크린샷·사진(`input/`)과 결과(`output/`)는 커밋하지 않는다(개인 사진). 결과는 `~/Desktop/mongdol-appstore/` 로도 내보낸다.
- App Store 는 알파 채널 PNG 를 받지 않는다 — 결과는 알파 없는 PNG.
- 검증: 6장 이어 붙인 전체 · 스토어 썸네일 크기(약 230px 폭)에서 큰 문구가 읽히는지.
