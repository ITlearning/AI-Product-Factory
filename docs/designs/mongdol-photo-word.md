# 몽돌 — 사진 한 단어

작성 2026-09-23 · 상태 **1단계 구현 (2026-09-23)** · 코드 `Color-Moments/` · 근거 실측 브랜치 `spike/mongdol-word-ai` (`338d594`)

하루 상세에서 사진을 누르면 그 순간에 어울리는 **순우리말 한 단어**와 **한 줄**을 보여준다.
위치가 있으면 아래에 지도를 둔다. 사진을 보는 일 자체를 조금 더 천천히, 감성적으로 만드는 게 목적이다.

> 색 고르기(탭 보정)를 기각하고 비운 자리다 (`Color-Moments/DESIGN.md` §3.4).

---

## 1. 이 설계가 지키는 것

| 제약 (SPEC §2) | 이 기능에서 |
|---|---|
| 1 오늘 색은 안 보여준다 | 단어는 **열린 하루(자정 이후)의 사진에만** 붙는다. 촬영물 뷰어(오늘 사진)에는 없다 |
| 4 재촉하지 않는다 | 단어가 아직 없다는 표시·「만들어 볼까요」 없음. 열면 그냥 있다 |
| 5 판단하지 않는다 | 한 줄은 하네스(§6)를 통과한 것만. 통과 못 하면 단어+뜻풀이만 |
| 사진은 기기 밖으로 안 나간다 | **그대로 참.** AI에는 글자(시간대·절기·색 이름·날씨·동네·후보 단어)만 간다 |

**바뀌는 약속**: 「서버 0 · LLM 0 · 로컬 저장만」(SPEC §9)은 깨진다. 위치(좌표)가 애플(지도·날씨)로, 동네 이름이 OpenRouter로 나간다.
권한 요청 문구와 앱 설명을 이에 맞게 고친다 (§9). **Tabber 승인 2026-09-23.**

## 2. 비목표

- 기기 안 모델(FoundationModels). iOS 26.1 실측 품질 미달(§11). iOS 27 이후 재평가.
- 사진을 AI에 보내는 것.
- 단어 목록을 실행 중에 공공 API에서 받는 것. (품질을 거를 수 없다 — §4)
- 지도 상호작용(끌기·확대). 그림 지도만.
- 서버에 사용자 데이터 저장. 중계는 상태가 없다.

  ↓ 16

- 지금의 「아무 데나 누르면 닫힘」은 없앤다 — 스크롤·지도와 충돌한다.

## 4. 단어 목록

**앱 안 JSON** (`Shared/Word/words.json`). Tabber가 100개 안팎을 고른다.

```json
{ "version": 1,
  "words": [ { "id": "neungae", "word": "는개", "meaning": "안개보다 굵고 이슬비보다 가는 비",
               "times": [], "weathers": ["drizzle","fog"], "seasons": [] } ] }
```

- `id`는 **절대 바꾸지 않는다.** 사진에 붙은 단어가 목록 갱신 뒤에도 유지되는 열쇠다.
- 빈 배열 = 조건 없음. `times`: dawn · morning · noon · afternoon · dusk · night. `weathers`: clear · cloudy · rain · drizzle · snow · fog · wind.
- 조약돌 이름 19개와 겹치는 말은 넣지 않는다(볕뉘·노을·너울…).
- **모으는 법**: 만들 때 한 번, 국립국어원 우리말샘·한국어기초사전·표준국어대사전 Open API로 빛·날씨·시간·계절 주제 고유어 후보를 뽑는다 → Tabber가 고른다 → 뜻풀이는 표준국어대사전과 대조.

**서버로 옮기기 쉬운 구조**

```
protocol WordSource { func words() async -> WordList }
 ├─ BundledWordSource      지금
 └─ RemoteWordSource       나중 — 정적 JSON 을 받고, 실패하면 Bundled
WordPicker                 순수 함수. 목록이 어디서 왔는지 모른다
```

## 5. 조건 → 후보

`PhotoContext` = 촬영 시각에서 **시간대·절기(24절기)·계절**, 이미 있는 색에서 **색 이름**, 있으면 **날씨·동네**.

`WordPicker.candidates(context, list, recentWordIDs)`:
1. 시간대·계절·날씨가 모두 맞는 단어 (조건 없는 칸은 통과)
2. 단어가 붙은 사진 중 최신 14장의 단어 제외 (열어 보지 않은 사진은 세지 않는다)
3. 0개면 날씨 → 계절 → 시간대 순으로 조건을 풀어 다시
4. 최대 8개. 순서는 사진 id 해시로 섞는다(같은 사진은 같은 후보)

**위치**
- 앱 안 촬영: 찍는 순간 `CLLocation` 저장 (When In Use).
- 잠금화면 촬영: **요확인** — 캡처 확장에서 위치를 받을 수 있는지 문서에 없다. 실기기로 확인.
- 날씨만을 위한 빌린 위치: 앱을 열 때의 대략 위치가 촬영과 **3시간 이내**면 날씨 조회에만 쓴다. 동네 이름·지도에는 쓰지 않는다.

**색 이름**: hex → 「옅은 금빛」「보랏빛 남색」 같은 한국어 이름. 새 함수(`ColorWording`)가 필요하다 — PebbleName 의 hue 구간을 확장한다.

## 6. 한 줄 생성

```
protocol PhraseService { func phrase(for req: PhraseRequest) async throws -> Phrase }
 └─ RelayPhraseService      몽돌 전용 중계 → OpenRouter
```

- **모델** `openai/gpt-6-luna` (OpenRouter 문자열 하나로 교체 가능). temperature 0.6 · max_tokens 1024 · reasoning low.
  - max_tokens 를 120 으로 두면 추론 모델이 추론에 다 써서 **빈 응답**이 온다(실측). 1024 유지.
- **요청**: 지시문 + 조건 + 후보(단어: 뜻) + **끝말 후보 3개**. 응답은 json_schema `{word: enum(후보), line: string}`.
- **끝말 회전**: 16개 끝말 중 최근 사진 6장에 쓴 것을 빼고 3개를 앱이 골라 넘긴다. 예시 문장으로 막으면 그 예시로 쏠린다(실측 v2: 「번져요」 11/20).
- **하네스** — 앱에서 검사한다(중계는 믿지 않는다). 하나라도 어기면 한 줄 버림:
  1. 단어 ∈ 후보
  2. 26자 이내 (조약돌 한 줄과 같은 상한)
  3. '-요'로 끝남
  4. 숫자 없음 (시각은 메타 줄에 있다)
  5. 따옴표 없음
  6. 금지 **패턴** — 글자가 아니라 쓰임으로 잡는다. `위로(해|하|받|를|가 되)` 는 걸리고 「회색 위로 먼동이」는 통과해야 한다. 우울 · 힘들/힘든/힘내 · 슬프/슬픈 · 외로 · 쓸쓸 · (행복한|좋은) 하루 · 기분 · (보|하|해)세요 · 괜찮아질
- **언제 만드나**: 그 사진을 **처음 열 때 한 번.** 결과를 사진에 저장하고 다시 만들지 않는다. 옛 사진 일괄 생성 없음.
- 실패(오프라인 등)면 단어만 저장하고, 다음에 열 때 한 줄만 다시 시도한다. 3회 실패하면 그만둔다.

**중계 (몽돌 전용, CodeStudy 와 코드 공유 없음)**
- Vercel 함수 `POST /api/phrase`. CodeStudy `Backend/src/llm/openrouter.js` 의 요청 모양을 **비스트리밍**으로 옮긴다.
- `X-App-Bundle-Id` 화이트리스트 + IP/기기당 하루 30회 (CodeStudy `rate-limiter.js` 방식).
- 상태·DB 없음. 로그는 console 만.
- 키 `OPENROUTER_API_KEY` 는 Vercel 환경변수. **OpenRouter 키에 월 지출 한도**를 건다(Tabber, 대시보드).

**비용** (실측 건당 ≈ $0.00015, 사진 한 장당 1회): 꾸준히 쓰는 1,000명이 하루 5장 → 월 약 $22.

## 7. 저장

`Moment` 에 선택 필드 추가 (없으면 옛 기록 그대로 읽힌다 — 테스트로 고정):

```swift
var place: Place?        // lat, lon, accuracy, name?   찍을 때
var weather: String?     // clear | rain | …            처음 열 때 조회
var word: PhotoWord?     // wordID, word, meaning, line?, ending?, attempts
```

- `word`/`meaning` 은 id 와 **함께 사본으로** 저장한다. 목록에서 단어가 빠지거나 뜻풀이가 고쳐져도 이미 본 사진의 말은 그대로.

## 8. 날씨

- WeatherKit, 지난 날짜 조회. Apple Developer 에서 WeatherKit capability 필요.
- 처음 열 때 한 번 조회해 `weather` 에 저장. 실패하면 날씨 없이 진행.

## 9. 권한·개인정보

- 위치 권한은 **앱 안 카메라를 처음 열 때** 1회 요청. 첫 실행에 묻지 않는다(재촉 금지).
- `NSLocationWhenInUseUsageDescription`: 「찍은 곳을 사진 옆 지도와 날씨에 씁니다. 위치는 지도·날씨를 불러올 때만 애플에, 한 줄을 지을 때 동네 이름만 보냅니다.」 (문구는 Tabber 확정)
- 사진 권한 문구 「사진은 기기 밖으로 나가지 않습니다」는 유지 — 여전히 참이다.
