# 몽돌 ENFP 웹판

iOS 앱 「몽돌」(`../Color-Moments`)을 **빌드 없는 정적 웹앱**으로 옮기고, 말투와 화면을 ENFP 기분으로 바꾼 판이다.
찍을 땐 색을 숨겨 뒀다가, 하루가 닫히면 그날 색으로 빚은 조약돌이 도착한다. 이 흐름은 원본과 같다.
그 위에 꽃이 피고, 컨페티가 터지고, 조약돌을 톡 건드리면 칭찬 한마디가 나온다.

## 실행

```bash
cd Mongdol-ENFP-Web
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

- 처음 열면 온보딩 세 장이 나온다(휴대폰 브라우저면 소개 다음에 「홈 화면에 추가」 한 장이 더 끼어 네 장). 마지막 장의 「견본 하루 채우고 둘러보기」를 누르면 지난 하루 16개(오늘 진행 중 포함)가 그림 사진으로 채워진다. 어제 하루는 일부러 안 받은 채로 남겨 둬서 바로 증정 세리머니가 뜬다.
- 나중에 채우려면 오른쪽 위 꽃 버튼(설정) → 「견본 하루 채우기」.
- 아래 떠 있는 탭바로 움직인다. 왼쪽 동그란 카메라 버튼을 누르면 iOS 선택 메뉴(사진 찍기 / 사진 보관함)가 뜬다. 자체 카메라 화면은 두지 않는다(Safari 가 들어올 때마다 권한을 묻고, 백그라운드 복귀 때 멈춘 프레임이 찍혔다). 캡슐은 「홈 · 모은 조약돌」이다. 원본의 가장자리 쓸기는 쓰지 않는다. iOS Safari의 「뒤로 가기」 몸짓과 겹치기 때문이다.
- ES 모듈이라 `index.html`을 더블클릭해서 `file://`로 열면 Chrome 같은 브라우저는 모듈을 막는다. 그럴 땐 3초 뒤에 「정적 서버로 열어 주세요」 안내가 뜬다. 정적 서버로 띄우는 게 기본이다.

### 홈 화면에 추가(PWA)

나중에 웹 푸시를 붙일 밑작업이다(iOS 웹 푸시는 홈 화면에 둔 앱에서만 된다). 푸시 코드는 아직 없다.

- `manifest.webmanifest` + `icons/`(원본 앱 아이콘 icon-1024 를 `sips` 로 180·192·512, maskable 512 는 420 으로 줄여 아이콘 테두리 색 `#0D0D12` 로 여백).
- `sw.js` — 같은 출처 요청은 **네트워크 먼저, 안 되면 캐시**(캐시 이름 `mongdol-v1`). 새로 배포하면 다음에 열 때 바로 새 판이 뜬다. 페이지는 쿼리(`?now=`·`?debug`)를 떼고 한 칸에 담아 오프라인에서도 뜬다. Google Fonts 같은 바깥 요청은 건드리지 않는다. 한 번 열어 SW 가 붙은 뒤 받은 파일만 오프라인에서 쓸 수 있다.
- `js/install.js` — 환경별 안내. 홈 화면 앱(`display-mode: standalone`·`navigator.standalone`)이면 안 띄움 · iOS 앱 속 브라우저(카카오톡·인스타·페이스북·라인·네이버 등)는 「Safari로 열기」 + 주소 복사 · iOS Safari 는 공유 → 홈 화면에 추가 → 추가 3단계 · Android 는 `beforeinstallprompt` 로 「홈 화면에 추가」 버튼(안 오면 ⋮ 메뉴 안내) · 데스크톱은 안내 안 함.
- 보이는 곳: 온보딩 소개 다음 한 장(홈 화면 앱·데스크톱이면 건너뜀), 설정 「몽돌 서랍」의 「홈 화면에 추가하기」(홈 화면 앱이면 숨김).
- **iPhone 은 Safari 탭과 홈 화면 앱의 저장소(IndexedDB)가 따로다.** 안내에 늘 적고, 이 Safari 에 기록이 있으면 「홈 화면에서 열면 새로 시작해요. 지금까지 담은 건 이 Safari 에 그대로 남아요」로 바꿔 말한다.
- 배포 폴더에 `manifest.webmanifest`·`sw.js`·`icons/` 가 같이 올라가야 한다. 캐시 구조를 바꿀 땐 `sw.js` 의 `CACHE` 버전을 올린다.

### 확인용 주소 인자

| 인자 | 하는 일 |
|---|---|
| `?now=2026-09-30T04:10` | 그 시각부터 시계가 흐른다. 새벽 4시 경계로 하루가 저절로 닫히는지 볼 때. **localhost·127.0.0.1이거나 `?debug`를 같이 붙였을 때만** 먹는다. 시각을 옮긴 동안은 저장소를 따로 쓰고(IndexedDB `mongdol-enfp-preview`, localStorage `mongdol.preview.*`) 화면 위에 「미리 보기 시각」 표시가 뜬다 — 미리 본 기록·받은 날이 진짜 기록에 남지 않는다 |
| `?onboarding` | 온보딩을 다시 띄운다(제품에는 「다시 보기」가 없다. 원본 §1.5) |
| `?debug` | 배포 주소에서도 위 확인 인자와 `window.__mongdol`(저장소 들여다보기)을 켠다 |

### 개발 도구

- `lab.html` — 조약돌 셰이더 실험실. 원본 아이콘 옆에 원본 합성(어두운 배경에 빛을 더하는 방식)으로 그린 돌, 밝은 배경 합성 hero/grid/photo, 날짜별 모양을 한 화면에 보여 준다.
- `tests/extractor.html` — 색 추출 회귀. 원본 `ColorExtractorTests`와 같은 사진 11장·기대값으로 비교한다. 원본 픽스처를 읽어야 해서 **상위 폴더(`AI-Product-Factory`)를 서버 루트로** 띄우고 `/Mongdol-ENFP-Web/tests/extractor.html`을 연다(원본은 읽기만 한다).

### WKWebView에 띄울 때

- `viewport-fit=cover`와 `env(safe-area-inset-*)`는 이미 들어 있다. 세로 전용 앱에 맞춰 폭 390~430 기준으로 짰다.
- 담기는 파일 입력(`<input type=file accept=image/*>`)이라 WKWebView에선 `NSCameraUsageDescription`·`NSPhotoLibraryUsageDescription`이 있어야 선택 메뉴의 「사진 찍기」가 뜬다.
- `file://`에서 ES 모듈이 뜨는지는 **요확인**이다. 확실한 길은 둘 중 하나다: `WKURLSchemeHandler`로 커스텀 스킴(`mongdol://`)에서 서빙하기, 또는 앱 안 로컬 서버.
- 글꼴은 Google Fonts에서 받는다. 오프라인이면 시스템 글꼴로 떨어진다(글꼴 파일을 번들하려면 `index.html`의 Google Fonts `<link>`를 빼고 `styles.css`에 `@font-face`를 두면 된다).

### 조약돌 셰이더

`SoftPebble.metal`을 GLSL로 한 줄씩 옮겼다: 짝짝이 달걀꼴 윤곽(배각 공식 울퉁불퉁), 돔 높이 → 해석적 법선 → 감싸는 빛(wrap), 테두리 빛(fresnel × 0.26), 입자(hash), 곡면 따라 처지는 18° 하루 색 띠, 후광·바닥 번짐·접지 그림자, 증정의 20° 반짝임 띠, 디더링.

- 작업을 시작할 때 받은 채택값: 지름 = 높이 × 0.76, 후광 hero 0.6 / grid 0.25 / photo 0.20, 바닥 번짐 hero 0.65 / grid 0.45 / photo 0, 캔버스 hero 1/0.54 · 그 외 1/0.66, photo는 그림자 35%. (앱 쪽 최신값은 이보다 작다 — 아래 한계 참고)
- 날짜별 모양은 `PebbleSilhouette` 해시 + `SoftPebbleShape(dayKey:)`와 같은 식. Swift로 같은 해시를 돌려 세 날짜의 seed·기울기·달걀꼴·울퉁불퉁 값이 소수 6자리까지 같은 걸 확인했다.
- 색 표(LUT 3줄 × 128칸)는 JS에서 `SoftPebbleUniforms.table`과 같은 방식으로 만든다(가우스 7탭 흐림 +10%, 테두리 +35%).
- **바꾼 것 하나: 바깥 합성.** 원본 후광은 어두운 배경에 빛을 「더하는」 방식이라 크림색 배경에서는 하얗게 날아간다. 그래서 돌 바깥(후광·바닥 번짐·접지 그림자)만 일반 알파 합성으로 바꾸고, 후광 색은 채도를 조금 올리고 살짝 밝혀 파스텔 빛이 되게 했다(`pebble-gl.js`의 `LIGHT_BG`, 셰이더의 `uBg`). 돌 표면 계산은 원본 그대로다. `lab.html` 맨 위 줄은 원본 합성 방식이라 비교해 볼 수 있다.
- WebGL 컨텍스트는 하나만 쓴다. 조약돌마다 그려서 2D 캔버스로 구워 캐시하고(최대 180개), 화면 근처(700px)에 올 때만 한 프레임에 10ms 예산 안에서 굽는다. 증정의 반짝임 띠만 매 프레임 다시 그린다. WebGL이 없으면 윤곽·띠·빛만 흉내 낸 2D 그림으로 대신한다.

조약돌 이름 19개는 우리말 그대로 두고 한 줄만 새로 썼다(`js/naming.js`). 감탄은 돌·색 그 자체와 「붙잡은 순간」에게만 한다. 그날 기분이 어땠는지도, 색이 좋고 나쁜지도(「어두운 색도」, 「럭키」 같은 말) 말하지 않는다. 「고른 색」처럼 기각된 색 고르기 기능으로 읽히는 말도 쓰지 않는다(교차 검증에서 걸러 고쳤다).

**즉흥 요소.** 홈 맨 위 「칭찬 한마디」(누를 때마다 바뀐다. 「오늘의」를 붙이면 매일 오라는 신호로 읽혀서 뺐다), 조약돌을 톡 건드리면 흔들리며 말풍선 칭찬과 꽃이 튀어나온다(홈·한 줄 행·상세·한 줌 어디서나).

**화면.** 원본의 `#06070A` 어둠 대신 크림·복숭아빛 바탕에 파스텔 번짐과 흩뿌린 꽃. 조약돌 둘레에 날짜마다 같은 자리에 꽃 두세 송이가 피어 살랑거린다. 사진 카드는 흰 테두리를 두른 폴라로이드 더미. 증정에는 꽃 화관이 스프링으로 톡톡 피고, 컨페티가 터지고, 꽃잎이 흩날린다. 셔터는 꽃 모양. 손글씨(나눔손글씨 펜)는 감탄하는 자리에만 쓰고, 이름은 원본처럼 명조, 본문은 고운돋움, 버튼은 IBM Plex Sans KR.

**색.** 원본 흰색 네 단계를 잉크 네 단계로 옮겼다(13:1 / 7.9:1 / 5.1:1 / 선). 날짜·캡션에 쓰는 3단계도 4.5:1 위다. 주 버튼은 레몬→복숭아 그라데이션에 짙은 글자.

## 지킨 원칙 (원본 SPEC §2)

- **찍을 때 색을 안 보여 준다.** 담기 화면엔 확인 문구와 사진 더미뿐. 진행 중인 오늘은 홈 배경을 물들이지 않고, 점선 돌만 두며, 상세의 시간축 띠·눈금·색 점, 사진 크게 보기의 색 점도 숨긴다.
- **스트릭·연속일수·배지·재촉 없음.** 오히려 「매일 안 와도 괜찮아요」, 「아무것도 안 담은 날도 완전 괜찮아요」를 말한다. 알림도 없다.
- **공유는 도구 공유만.** 설정의 「친구에게도 해보라고 하기」가 앱 주소를 건넨다(Web Share, 없으면 주소 복사). 조약돌·결과 이미지 공유는 넣지 않았다.
- **색 고르기 없음.** 기각된 기능이라 넣지 않았다.
- **격자·가로 스크롤 없음.** 한 줌도 격자가 아니다.
- **외부 전송 없음.** 사진과 기록은 이 브라우저의 IndexedDB·localStorage에만 있다. 분석·로그 수집 코드는 없다. 밖으로 나가는 요청은 Google Fonts 글꼴 파일뿐이다.

## 교차 검증 뒤 고친 것

독립 검증에서 FAIL로 나온 항목을 이렇게 고쳤다.

1. `?now=`가 배포본에서도 켜지던 것 → localhost·`?debug`에서만. 시각을 옮긴 동안은 저장 이름공간을 따로 쓴다(`js/clock.js`, `js/db.js`).
2. 파일 입력으로 들어온 사진이 EXIF 시각을 쓰고 `addedAt`이 비어, 마무리 뒤 넣은 사진이 열린 조약돌 색을 바꾸던 것 → 파일로 들어온 건 전부 `addedAt`=지금, 셔터 쪽(`capture` 입력)은 `capturedAt`도 지금으로 고정. 앨범은 EXIF → `lastModified`(0 이하·미래면 지금) 순(`js/capture.js`).
3. 같은 사진 두 번 저장 → 이름·크기·수정 시각으로 거른다(`store.hasFileSig`).
4. 디코드 실패·저장 실패 때 「담는 중…」에서 멈추던 것 → 한 장씩 try/catch, 실패·중복 개수를 토스트로.
5. 문구 — 「당신이 고른 색은 늘 옳아요」 → 「당신이 붙잡은 순간은 늘 옳아요」, 색·그날을 평가하던 한 줄(먹빛·볕뉘·그믐·잿빛·안개·해미·이끼·너울·새벽빛)을 돌·색 자체에 감탄하는 말로, 「오늘의 칭찬」 → 「칭찬 한마디」, 「오늘은 아직 텅텅!」 → 「오늘은 아직 비어 있어요」.
6. 첫 기록 때 `navigator.storage.persist()` 요청 + 아래 한계에 Safari 저장소 삭제를 적었다.

그 밖에: 이미 04시가 넘어 닫혔으면 마무리 버튼이 시트를 그냥 닫는다(원본과 같게), 카메라 권한 대기 중 재진입 가드와 권한 대기 사이 닫았을 때 스트림 정리, 닫히는 0.44초 사이 다시 열기, 창이 가려져 있을 때 증정 예약 안 함, 사진 주소 캐시 상한(240)·오래된 것 해제·실패는 캐시 안 함, `window.__mongdol`은 디버그일 때만, 카메라 화면에선 토스트를 컨트롤 위로.

## 확인 못 한 것 · 알려진 한계

- **조약돌 크기·후광 값이 앱의 최신값보다 이전 값이다.** 웹은 지름 0.76, 후광 hero 0.6·grid 0.25·photo 0.20, 바닥 0.65·0.45를 쓴다. 앱은 그 뒤 지름 0.70, 후광 hero 0.4·grid 0.18·photo 0.15, 바닥 0.5·0.35로 바뀌었다. 다음에 `js/pebble-gl.js`의 `SOFT_DIAMETER`·`GLOW`를 맞출 것.

- `?now=` 막힘(배포 주소에서 무시되는지)은 코드로만 확인했다. 확인 환경이 전부 127.0.0.1이라 실제로 다른 호스트에서 열어 보지는 않았다.

- **실기기(iPhone Safari·WKWebView)에서 돌려 보지 않았다.** 스크롤 매끄러움, 스와이프 손맛, 스프링 모션, 카메라는 실기기에서만 판정된다. 헤드리스엔 카메라가 없어 getUserMedia 경로는 「카메라가 부끄럼을 타나 봐요」 대체 화면까지만 봤다.
- WKWebView에서 `file://` ES 모듈 로딩은 요확인(위 참고).
- 사진 한 단어: 원본은 기기 안 모델(TinyCLIP)이 사진을 보고 1,792개 중에서 고른다. 웹엔 모델이 없어서 사진에 뭐가 찍혔든 참인 말만 쓴다 — 원본 규칙 경로의 「때」 단어 28개 + 날짜 사실 단어 73개(명절·음력·철, 2026-10-06 Tabber 확정). 판정(시각·해 높이·달 나이·음력·양력)은 원본 `WordPicker.judge` 그대로이고 해·달 계산은 Swift 와 소수 여섯째 자리까지 같다. 날씨·기온 말은 웹이 날씨를 몰라 뺐다. 최근 14장의 단어와 그날 조약돌 이름은 피하고, ↻ 는 사진마다 한 번 다른 갈래로 바꾼다. 쉬게 한 말(rest)은 맞는 말이 없을 때만 쓴다.
- 원본에 있는 것 중 안 옮긴 것: 잠금화면 카메라 컨트롤·위젯·아침 도착 알림·iCloud 이어 보기(웹에 없는 자리), 추천 사진으로 첫 조약돌 받기(Vision 점수), 조약돌 카드 만들기(결과 이미지 공유라 뺐다), 핀치 줌·배율 알약, 알약을 잡고 끌어 달 단위로 훑기(알약은 보이기만 한다), 둥근 돌/반듯한 돌 고르기(예전 모양은 2D 대체로만 남았다).
- 사진은 긴 변 1280px로 줄여 저장한다(원본은 원본 해상도). 브라우저 저장소를 지우면 기록도 사라진다.
- **Safari는 오래(약 7일) 열지 않은 사이트의 저장소를 지울 수 있다.** 첫 기록을 남길 때 `navigator.storage.persist()`로 「지우지 말아 달라」고 청하지만, 받아 줄지는 브라우저가 정한다. 홈 화면에 추가한 웹앱이나 WKWebView 앱 안에서는 이 규칙이 다르게 적용된다(요확인). 기록을 오래 지키려면 앱 쪽 저장소로 옮겨야 한다.
- 같은 사진 두 번 담기는 파일 이름·크기·수정 시각이 같을 때만 거른다. 같은 사진을 다른 이름으로 저장해 다시 고르면 두 번 들어간다.
- 글꼴은 네트워크가 있어야 원래 모양으로 나온다.
- 견본 사진은 캔버스 그림이라 실제 사진보다 단순하다. 사진이 들어가면 인상이 꽤 달라진다(원본 DESIGN §7과 같은 주의).
