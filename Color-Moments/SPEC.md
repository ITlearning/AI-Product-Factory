# 몽돌 (Mongdol) — 현재 앱 스펙

> **이 문서의 용도**: 디자인 작업의 입력. **지금 코드에 실제로 있는 것만** 적는다
> (수치는 소스에서 긁었다). 기획 의도·기각된 안·경쟁 분석은 [`../docs/designs/color-moments.md`](../docs/designs/color-moments.md)에 있다.
>
> 기준 시점 2026-09-22 · 미출시 · iOS 18.0+ · iPhone 전용 · **세로 고정**

---

## 1. 이 앱이 하는 일

**지나가다 눈에 걸린 색 한 점을 붙잡고, 하루가 끝나면 그날의 색들이 조약돌 하나로 열린다.**

- 찍는 순간에는 **색을 보여주지 않는다.** 자정(새벽 4시 경계)에 한 번 열린다.
- 하루에 조약돌 하나. 조약돌은 그날 색들의 그라데이션을 담은 물건이다.
- 주 진입은 **잠금화면 카메라 컨트롤 1초.** 앱을 여는 건 찍으러가 아니라 **보러** 오는 것.

---

## 2. 절대 제약 — 디자인이 깨면 안 되는 것

이 다섯은 제품의 정체성이다. 예뻐 보인다는 이유로 넘으면 다른 앱이 된다.

| # | 제약 | 깨지면 |
|---|---|---|
| 1 | **오늘 색은 안 보여준다** | 「자정에 열린다」가 사라지고 그냥 색 일기 앱이 된다 |
| 2 | **격자로 깔지 않는다** — 조약돌은 한 줄로 이어붙인다 | 빈 날이 구멍으로 보이고 그 순간 스트릭이 된다 |
| 3 | **스트릭·연속일수·성취 배지 없음** (영구 비목표) | 이 앱이 벌을 주기 시작한다 |
| 4 | **재촉하지 않는다** — 미보정 표시·「확인해주세요」·알림 badge 없음 | 수집이 숙제가 된다 |
| 5 | **판단하지 않는다** — 「우울한 하루였네요」 같은 말은 없다 | 색은 기분이 아니다 |

부수 규칙: 안 담은 날은 **조약돌이 없을 뿐 빠진 게 아니다.** 빈 날을 그리지 않는다.

## 3. 화면

7개. 괄호 안은 파일.

### 3.1 홈 (`ColorMoments/App/HomeView.swift`) — 진입점

```
[내비]  몽돌                                    🔧(DEBUG만)
┌────────────────────────────────────────┐
│ 오늘 2개 담겼어요                        │  ← 색 없음
│ 색은 자정에 열려요                       │
└────────────────────────────────────────┘

모은 하루
  ⬤ 노을        ⬤ 볕뉘        →(가로 스크롤)
  9월 21일      9월 19일
  16:10–17:25   11:10–11:35

              ( ◯ )                        ← 셔터
   잠금화면 카메라 컨트롤로도 담을 수 있어요
```

- **오늘 카드**: 개수만. 0개일 때 「오늘은 아직 비어 있어요 / 지나다 눈에 걸리는 게 있으면 눌러요」
- **모은 하루**: 가로 스크롤. **오늘은 여기 없다** (아직 끝나지 않은 하루)
- **빈 상태**: 점선 원 + 「아직 모은 하루가 없어요 / 오늘 담은 것은 자정에 조약돌이 돼요」
- 조약돌 탭 → 3.4 · 셔터 탭 → 3.2

### 3.2 촬영 (`Shared/Capture/CaptureScreen.swift`)

앱 안과 잠금화면 확장이 **같은 화면**을 쓴다. 의도적으로 비어 있다 — 줌 배율 말고는 아무 선택도 없다.

- 전면: 카메라 프리뷰 (핀치 줌)
- 배율 알약 `.5 / 1× / 5` — 활성은 호박색 `#FFD640`
- 셔터 74pt 원
- 우하단 **촬영물 더미**: 찍은 사진이 카드처럼 겹겹이 쌓임 (최대 4장 보이고 총 개수 배지)
- 찍으면: 흰 플래시 0.12초 + 확인 문구 캡슐. **색은 안 보여준다**
- 잠금화면 확장에서만: 「위로 쓸어올리면 닫혀요」

### 3.3 증정 (`Shared/Day/BadgeCeremony.swift`) — 이 앱의 유일한 보상

자정 이후 첫 실행에 **하루 한 번** 전체 화면으로 뜬다. 짧고 조용해야 한다.

```
      어제가 담겼어요        ← 오늘/어제/그날 중 날짜에 맞는 것

          ⬤                 ← 조약돌 150pt, 표면을 빛이 한 번 훑는다

         노을
      저무는 빛도 빛이에요.
         9월 21일
     16:10 – 17:25 · 4개

         닫기
```

배경: 검정 + 그날 그라데이션을 blur 110으로 화면 전체에 42% 번지게. 등장이 끝나면 9초 주기로 아주 천천히 숨쉰다.

### 3.4 하루 상세 (`Shared/Day/DayMomentsView.swift`)

**앨범이 아니다.** 한 하루만 보여주고 옆 날로 가는 길이 없다.

- 상단: 조약돌 120pt + 이름
- 격자: 그날 사진 썸네일 (각 96pt, 우하단에 그 순간의 색 점)
- 「사진을 눌러 그 순간의 색을 고를 수 있어요」
- 사진 탭 → 3.5

### 3.5 ~~색 고르기~~ — 2026-09-23 삭제 (DESIGN §3.4). 사진 탭은 크게 보기(`Shared/Day/DayPhotoView.swift`)로 바뀌었다

크게 보기 화면은 사진 아래에 순우리말 한 단어(명조)·뜻풀이·시각을 보여준다. 단어는 처음 열 때 시간대·계절로 고르고(`Shared/Word/`) 사진에 저장해 다시 바뀌지 않는다. 닫기는 좌상단 알약 또는 맨 위에서 당기기.

자동 추출의 상한을 넘는 유일한 수단. **안 해도 된다** — 기본값은 자동이다.

- 사진 전체 (원본 해상도). 아무 데나 누르면 그 점의 색
- 누른 자리에 34pt 표식 — 고른 색으로 채워진 원 + 흰 테두리
- 하단: 현재 색 44pt 스와치 + HEX + 「직접 고른 색 / 자동으로 뽑은 색」
- 그 아래: 「사진에서 많이 나온 색」 자동 후보 5개 (38pt). **후보는 거들 뿐** — 없는 색도 사진에서 집을 수 있다
- 우상단 「자동으로」: 고른 적 있을 때만 나타남

## 4. 핵심 컴포넌트

### 4.1 조약돌 (`Shared/Day/DayBadge.swift`)

하루 하나. **구슬·카드와 나란히 놓고 고른 결과.**

- **모양**: 위아래 둥글기가 다른 육각형에 가까운 형태 (`PebbleShape`)
- **날마다 다르게 생겼다.** 날짜 문자열 해시로 결정론적으로 뽑는다 — 같은 날은 언제나 같은 모양

| 속성 | 범위 |
|---|---|
| 폭 비율 (높이 대비) | 0.58 – 0.76 |
| 위쪽 둥글기 | 0.38 – 0.52 |
| 아래쪽 둥글기 | 0.34 – 0.50 |
| 기울임 | −4° – +4° |

- 높이 = `size × 1.2`
- 표면: 그라데이션 + 좌상단→우하단 광택(흰 26% → 투명 → 검정 10%, plusLighter) + 흰 22% 1pt 테두리
- 그림자: 검정 24%, radius 5, y+3

**만지는 반응은 전부 뺐다** (누르면 눌림·문지르면 빛남·기울기 광택). 반응을 얹을수록 장면이 뿌예졌다. 조약돌은 **보는 것**이다.

### 4.2 하루 그라데이션 (`Shared/Day/DayGradient.swift`)

- 그날 순간들의 색을 **위에서 아래로** — 아침이 위, 밤이 아래
- **시간 간격이 유지된다.** 첫 촬영~마지막 촬영을 0~1로 펴되 그 안의 비율은 그대로 → 저녁에 몰아 찍은 날과 고르게 찍은 날이 다르게 생긴다
- 순간 1개면 단색

### 4.3 슁 (표면을 훑는 빛)

증정에서 조약돌이 안착한 뒤 한 번. 조약돌 **안쪽에서** 그린다(바깥 overlay면 사각형이 지나간다).

- 띠 폭 = 조약돌 폭 × 1.15, 20° 기울임, 흰 심지 최대 30%
- 진행도 0→1, 이동 폭 ±1.05w. 양 끝 20%에서 스스로 투명해진다
- **회귀 테스트로 고정**: 중간엔 밝고 · 양 끝은 안 그린 것과 픽셀 단위로 같고 · 한복판에도 조약돌을 덮지 않는다

디자인 대상이다. 지금은 **체계 없이 그때그때 정한 값들**이다.

## 6. 모션 (실측 타이밍)

### 증정 등장 — 총 1.9초

| 시각 | 무슨 일 |
|---|---|
| 0.15s | 조약돌이 아래에서 떠오르기 시작. **자리는 스프링**(response 0.80 / damping 0.90), **투명도는 easeOut 0.80s** — 곡선을 나눠야 「떠오르며 나타난다」가 된다 |
| 0.95s | 안착. 촉감(햅틱)이 여기서 온다 |
| 0.95 – 1.90s | 표면을 빛이 한 번 훑는다 (easeInOut 0.95s) |
| 1.30s | 이름·날짜가 뒤따라 온다 (easeOut 0.55s) |
| 1.90s~ | 배경 그라데이션이 9초 주기로 숨쉬기 시작 |

> **스프링을 투명도에 같이 걸면 안 된다.** 오버슛이 0→1을 먼저 찍어서 「뚝 떴다가 움직이는」 그림이 된다.

### 그 밖

- 촬영 플래시 easeOut 0.12s · 확인 문구 0.2s
- 촬영물 더미 쌓임: 스프링 0.42 / 0.66, 셔터 쪽에서 날아와 얹힘
- 색 고르기 표식: 스프링 0.30 / 0.70

## 8. 디자인이 답해야 할 빈칸

지금 **비어 있거나 어긋난** 것들. 우선순위 순.

1. **브랜드가 없다.** AccentColor 미정의, 로고 없음, 앱 아이콘은 자리만 채운 상태.
   이름 「몽돌」(파도에 닳아 둥글어진 돌)에서 나와야 한다.
2. **다크 처리가 세 갈래다.** 홈 `white 0.04` · 증정/색 고르기 `black` · **하루 상세는 배경 지정이 아예 없다.**
   한 값으로 모으든 층위를 정하든 결정이 필요하다.
3. **회색 단계가 즉흥적이다.** 흰색 불투명도가 0.22 / 0.32 / 0.35 / 0.40 / 0.45 / 0.55 / 0.62 / 0.85 로 흩어져 있다.
4. **빈 상태가 약하다.** 첫날 화면이 사실상의 온보딩인데 지금은 점선 원 하나다. (Q4 — 미해결)
5. **조약돌 광택이 평면적이다.** 지금은 대각선 그라데이션 한 겹. 「파도에 닳은 돌」의 물성이 아직 안 나온다.
6. **촬영 화면만 톤이 다르다.** 기본 카메라를 닮아 있어서 나머지 화면과 안 붙는다.
7. **아이콘을 거의 안 쓴다.** 셔터·점선 원·공구(DEBUG)뿐. 의도인지 미완인지 결정 필요.

- 다크 전용 (`preferredColorScheme(.dark)`)
- 사진은 원본 그대로 저장(4032×3024급). 격자는 축소본, 큰 화면은 원본
- **EXIF 방향 주의**: 세로 사진은 픽셀이 가로로 저장된다. 사진 좌표를 쓰는 디자인(탭·크롭·오버레이)은 방향 적용 후 계산해야 한다
- 한국어 전용. 로컬라이즈 구조는 아직 없음

---

## 10. 아직 없는 것

디자인 시 **있다고 가정하면 안 되는 것들.**

- 사진첩에서 가져오기 (B 경로)
- 공유 / 내보내기
- 온보딩
- 설정 화면
- 알림
- 위젯 (컨트롤 위젯만 있고 홈 화면 위젯 없음)
- 주/월 단위 모아보기
