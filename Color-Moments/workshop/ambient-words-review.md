# 몽돌 1.2 — 위젯·자동 줍기 후보 말(ambient) 검토표

설계: `docs/designs/mongdol-1.2-words.md` R1. 위젯·잠금화면·사진 자동 줍기는 **`moment` 74개 + `ambient: true` 말**에서만 고른다.
기준: 사진 없이 **지금 시각·해 높이·달 나이·날짜(음력·양력)·날씨·기온**만으로 맞다고 판정할 수 있는 말. 계절·달(月)만으로 정해지는 말, 사진 속 물건·장소·일이 있어야 맞는 「장면 말」은 뺐다.

원천: `subjects` 가 비고 판정할 조건이 하나 이상인 말 중 `moment` 아닌 것 359개 → **넣음 161개 · 애매함 69개 · 뺌 129개**.

검토 방법: 넣음에서 이상한 말은 지우고, 애매함에서 살릴 말에 표시만 해 주세요. 조건(시각·날씨 범위)을 고칠 말은 새 id 가 필요합니다(이미 있는 id 의 조건은 좁히기만 가능).
